## Task: T-009 — Dispatch to the correct pass evaluator per drill

### What I changed
- `src/session/DrillRunner.ts`: Updated `DrillRunner._score()` to check if the drill's pass criteria includes `decouplingScoreThreshold`. If it does, we route the check through `evaluateIndependencePass` (R1, R2). We pass `msg.decouplingScore` into the check (R3). If `evaluateIndependencePass` fails and returns a message, we override the default diagnosis headline with this custom message and move the original headline down to `detail`, preserving existing messaging while promoting the decoupling feedback (R5).
- `src/session/__tests__/runner.test.ts`: Created new unit test file using `@vitest-environment jsdom` and mocking `audioEngine` and `midiEngine` in order to test `DrillRunner` dispatch directly (R-T1, R-T2, R-T3). 

### User-reachable path
Any hi-hat independence drill (e.g. "Basic Decoupling" via the bootcamps menu). The decoupling logic is now actively evaluated upon completing the drill, meaning a drummer whose hands and feet are tightly coupled will now see a fail and the correct pedagogical message.
