### Notes for review
Created a separate `offlineEnterApp` helper instead of reusing `enterApp` from `e2e/helpers.ts`. The existing helper tries to directly `import('/src/audio/midi.ts')` to await the engine initialization, which fails in the offline suite because it runs against the built `vite preview` artifact where the uncompiled `.ts` source file is missing. The new helper circumvents this with Playwright's `toPass` for robust asynchronous polling on the DOM element's `data-phase` instead.
