## Task: T-016 — The collection window must follow the latest note, not the last array element

### What I changed
- `src/session/DrillRunner.ts`: Changed the `lastNoteMs` calculation to use `reduce` and `Math.max` over the entire sequence instead of reading the last array element, ensuring the hit collection window covers the entire drill regardless of array order.
- `src/session/__tests__/runner.test.ts`: Added test `R-T3: Collection window extends to the latest note, not the last array element` to verify that an unsorted sequence still correctly sets the sleep duration based on the latest note in the sequence.

### User-reachable path
The user reaches this logic when playing any drill in the app via the drill session screen (`?drill=<id>`), as this handles the hit collection window for real MIDI drum hits.
