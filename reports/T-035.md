### Notes for review
- Using just `canvas.width !== Math.round(rect.width)` still threw the error once per mount (because it wrote to the DOM during the observer's callback phase, dirtied the layout tree, and got aborted by the browser). Using `requestAnimationFrame` correctly shifts the DOM write out of the callback phase and eliminates the error entirely.
- Playwright E2E test limits were strictly observed to avoid starving the parallel hardware task, running only `rhythmgrid.spec.ts` as directed by the spec overrides.
